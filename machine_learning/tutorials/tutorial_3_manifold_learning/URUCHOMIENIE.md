# Uruchomienie zestawu

1. Rozpakuj całe archiwum, zachowując strukturę katalogów.
2. Otwórz katalog główny w JupyterLab.
3. Dla studentów rozpocznij od `student/00_START_TUTAJ.ipynb`.
4. Notebook projektu automatycznie szuka danych w katalogu `data/` znajdującym się poziom wyżej.

Instalacja zależności:

```bash
python -m pip install -r requirements.txt
```

Kolejność notebooków studenckich:

1. `student/01_macierze_grafy_algorytmy_TODO.ipynb`
2. `student/02_MDS_tSNE_UMAP_TODO.ipynb`
3. `student/03_PROJEKT_miejscowosci_polaczenia_TODO.ipynb`

Pełne rozwiązania znajdują się w katalogu `prowadzacy/`.
