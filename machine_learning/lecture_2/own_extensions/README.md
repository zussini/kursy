# Own extensions for lecture 2

This directory contains local teaching extensions extracted into clean,
self-contained notebooks. They preserve the course-specific material without
vendoring text, figures, data files, or full notebook structure from Python Data
Science Handbook.

Notebooki:

- `01_pandas_multiindex_nd.ipynb` - MultiIndex jako reprezentacja danych 3D/4D.
- `02_numpy_meshgrid_exercises.ipynb` - `reshape`, `ravel`, `meshgrid` i punkty siatki.
- `03_matplotlib_3d_4d_tesseract.ipynb` - rzutowanie 4D oraz wizualizacja teseraktu.

For external background reading, link to upstream sources directly instead of
copying third-party notebooks into this repository.
